# Sprint 1.10: Wiki Discovery & Reference Engine

## 1. The Constitution (Discovery Mandates)
1. **Interaction Standard:** Direct DOM manipulation (e.g., `document.addEventListener`) is strictly forbidden for global shortcuts and outside-clicks. The agent MUST use `@vueuse/core` (`useMagicKeys`, `onClickOutside`) for all global UI interactions to maintain Vue Virtual DOM purity.
2. **Query Performance:** The Command Palette and Editor Autocomplete inputs MUST be debounced (minimum 300ms) to prevent Supabase RPC endpoint flooding.
3. **Backlink Statelessness:** Backlinks (inbound references) must be computed dynamically at runtime using PostgreSQL pattern matching (`.ilike('%[[Title]]%')`). The domain model must never store a hardcoded array of backlink UUIDs, preventing state desynchronization.
4. **Editor UI Purity:** The Wiki-Link autocomplete picklist must overlay the editor using standard CSS absolute/fixed positioning and Vue state, avoiding heavy third-party dropdown libraries.

## 2. The Product Spec (User Flows)
* **Flow 1: Command Palette Search:** A user presses `Cmd+K` (or `Ctrl+K`). A modal overlay appears. As they type, debounced queries hit the `search_wiki` RPC. Results are displayed, grouped by `entity_type`. Pressing `Escape` or clicking outside closes the modal.
* **Flow 2: Dynamic Backlinks:** A user navigates to the "Goblin Ambush" page. At the bottom of the page, a "Referenced By" section appears, automatically listing and linking to "Session 4 Notes" and "The Whispering Woods" because those pages contain `[[Goblin Ambush]]` in their raw markdown content.
* **Flow 3: Authoring Autocomplete:** In the GM Editor, the user types `[[`. A small picklist overlay appears at the cursor (or near the editor). The user types "Harp", the list filters to "The Harpers", they select it, and `The Harpers]]` is injected into the editor text.
