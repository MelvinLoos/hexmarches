# Sprint 1.13: WYSIWYG Visual Parity & Discoverability

## 1. The Constitution (Mandates)
1. **Visual Parity:** A parsed `[[Wiki-Link]]` must render inside the TipTap editor as a real Vue component (styled badge), **not** raw `[[ ]]` bracket text. Serialization to raw Markdown (`[[Title]]`) must remain byte-identical so the database / Nuxt MDC renderer contract is untouched.
2. **Headless UI Construction:** TipTap stays headless. All link affordances live in the existing Tailwind-styled Bubble Menu and Slash Menu.
3. **Discoverability:** The wiki-link intent must be reachable without memorizing the `[[` trigger:
   * Bubble menu **Link** button wraps the current text selection in a `wikiLink` node.
   * Slash menu **Link Page** entry opens the suggestion autocomplete at the cursor.
4. **SSR / Clipboard Integrity:** `renderHTML()` is preserved alongside `addNodeView()`. Only the in-editor viewport uses the Vue NodeView; `getHTML()`, clipboard copies, and headless/SSR rendering continue to use the original HTML serialization.

## 2. The Product Spec (User Flows)
* **Flow 1 — Visual Parity:** A GM loads a page containing `[[The Harpers]]`. The editor parses this and displays a styled `# The Harpers` badge in the text flow (not `[[The Harpers]]`). Saving emits the original `[[The Harpers]]` markdown unchanged.
* **Flow 2 — Bubble Link:** A GM selects text (`The Harpers`) and clicks the `🔗` button on the selection bubble menu. The selection is replaced by a wiki-link badge; saving emits `[[The Harpers]]`.
* **Flow 3 — Slash Discoverability:** A GM presses `/` on an empty line, types "link", and presses Enter on **Link Page**. The `[[` trigger is inserted at the cursor and the wiki-link autocomplete picklist opens immediately.

## 4. Test Conventions Introduced
* Deep DOM mounting: harnesses mount with `attachTo: document.body` so the real `.ProseMirror` view and teleported menus are queryable.
* ProseMirror layout math (`coordsAtPos`) is stubbed in jsdom (no `getClientRects`); every other editor interaction is real (commands, transactions, suggestions, Vue components).
* Extension commands returning `chain().x().run()` must use the injected chain (`chain()`) — the `CommandManager` dispatches the shared transaction exactly once (`mismatched transaction` otherwise).
